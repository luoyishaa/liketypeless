# v1 SenseVoice 候选路由锁定

2026-09-30 在读取工程保留集结果之前，按旧 Common Voice 21 zh-CN `test` 中与公开朗读集隔离的 100 条 1–4 字短句选择候选时长阈值 **4.0 秒（含端点）**。生产决策只使用音频实际时长，不读取参考文本或识别结果；超过阈值保持 Whisper small。阈值不随保留集结果调整。

开发集的两份预测以样本 ID 和转换后音频 SHA-256 配对：发布 Python 环境的 Whisper small `/stt/transcribe` 与官方 `SenseVoiceSmall-GGUF` q8 Windows CPU CLI。4.0 秒路由到 SenseVoice 的样本为 86/100；原始 CER 从 Whisper 的 195/343（56.8513%）到候选路由的 148/343（43.1487%），相对错误减少 24.1026%；按说话人聚类、固定种子 5000 次自助抽样的 CER 改善 95% 区间为 3.5191–23.5465 个百分点。该开发集用于选阈值，不能作为保留集收益或安装版性能宣称。

候选命令逐条启动新进程，包含模型加载；基线为已有产品 Python 接口。因此两者当前的延迟不可直接比较。模型来自 `FunAudioLLM/SenseVoiceSmall-GGUF` 固定版本 `90c1c61912018b70ada0fcc024ea24aca62f2e63`，运行程序来自 FunASR `runtime-llamacpp-v0.2.6` Windows x64 CPU 发布包。集成前仍须通过保留集配对质量门槛、封装后延迟与失败回退、第三方许可清单及独立机器验证；未通过则保留 Whisper 单模型。

## 冻结后工程保留集的产品接口配对结果

同一台 Windows 11 主机、同一音频、同一 Whisper small GPU 基线，候选走 `/stt/transcribe` 的 `local-routed` 提供者；SenseVoice 使用发布方便携 CPU 程序。数据为官方 AISHELL-1 **train** 中另选且说话人隔离的工程保留集，不是官方 test 排名，也不是安装版测速。

| 分层 | 样本 | Whisper 字错误 / 参考字 | 4 秒路由字错误 / 参考字 | 相对错误减少 | SenseVoice 路由条数 | 按说话人聚类的 CER 改善 95% 区间 |
|---|---:|---:|---:|---:|---:|---:|
| 短句 v2 | 100 | 139 / 700 = 19.8571% | 62 / 700 = 8.8571% | 55.40% | 99 | 8.2171–13.8187 个百分点 |
| 朗读 | 300 | 612 / 4289 = 14.2691% | 525 / 4289 = 12.2406% | 14.22% | 129 | 1.1585–3.2522 个百分点 |

两层均达到预先固定的质量条件：短句相对 CER 降低超过 20%，区间不含零；朗读未退化。保留短句原始接口请求 P50/P95：Whisper 为 136.006/163.579 ms，路由为 767.179/971.727 ms；朗读为 143.102/204.060 ms 与 218.315/1084.917 ms。这个速度取舍不能隐藏：CPU 候选改善识别，但短句中位请求多约 0.63 秒。首次请求、录音、整理、目标窗口恢复与粘贴均不属于这些 P50/P95。最终安装版和真实录音路径还需单列测量。

## 候选包同二进制后台复测

`0.1.0-rc.3` 安装包内的 PyInstaller 后台与本次评测后台 SHA-256 同为 `7e5eab3029a698ffbb09afd153dbdb26d85cdd59f942f208df2ffd6ae4a4c7f2`。同一台 Windows 11 10.0.26200、i7-14650HX、RTX 5060 Laptop GPU 主机；Whisper 用 CUDA float16，SenseVoice 便携程序用 CPU。官方模型按固定 SHA-256 下载并校验后运行。两组配对使用同一批准备音频、同一后台可执行文件；候选仅改变请求的识别提供者。分组与置信区间的可公开汇总为 [v1-rc3-packaged-route-summary.json](../reports/v1-rc3-packaged-route-summary.json)。

上述 P95 是已准备文件交给已启动后台后的 HTTP 请求耗时，未主动预热，首次请求单列在 JSON；**不是**停止录音到文字可用的桌面延迟，也不是 NSIS 安装后独立机器的成绩。SenseVoice 提升原始 CER 但增加暖态请求等待；Whisper 在不同轮次有小幅非确定性，因此正式比较必须用同一次同二进制配对报告，不从不同历史轮次拼接最优数值。产品在模型未准备、CLI 失败或格式处理失败时回退 Whisper，并报告实际提供者。44.1 kHz 麦克风短录音转换到 16 kHz 的路径已单独做同音频探针；保留集本身全部为事先准备的 16 kHz 音频。
