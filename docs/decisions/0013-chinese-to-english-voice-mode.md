# 0013. 中英语音输入先整理中文再翻译

## 决策

添加持久化的 `zh-to-en` 输出模式。语音始终按中文转写，先经过现有保守中文整理，再调用本地 Ollama 将整理结果翻译成英文，最后才粘贴。

## 原因

直接让 ASR 输出英文无法解决中文口语表达、中文专名和句子结构的识别问题。保留中文转写与整理阶段能复用已经验证的安全回退，再把翻译限定为最后一步。

## 后果

- 翻译遵循本地优先原则，使用当前配置的 Ollama 模型，不增加云服务。
- 翻译失败会阻断自动粘贴并显示错误；不会把中文原文冒充英文输出。
- 预览始终显示中文原始转写，最终文本才因模式不同而变化。
