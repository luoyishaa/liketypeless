# 0012. 快捷键和输入设备使用 Electron 本地持久化设置

## 决策

全局快捷键和输入设备编号保存到 Electron 的用户数据目录 `settings.json`。主窗口可直接修改：快捷键立即注销旧值并尝试注册新值，输入设备在下一次开始录音时作为 API 请求参数传入。

## 原因

快捷键属于系统级 Electron 能力，音频设备由 Python API 控制；把设置写在其中一侧会造成另一侧需要重启或读取不一致。由桌面主进程保存并在启动录音时显式传递，可以保持职责清晰，也避免为简单偏好引入数据库或云同步。

## 后果

- 无效或被其他程序占用的快捷键不会覆盖当前已注册快捷键，界面会显示错误。
- 已选设备只对后续开始的录音生效，避免在活跃 stream 上切换硬件。
- 首次使用以及缺失、损坏的设置文件都回退到 `Shift+Space` 和系统默认输入设备。
- 设置不进入 Git，也不会离开本机。

## 验证

1. 在设置栏输入 `Ctrl+Shift+Space` 并失焦，确认托盘提示的快捷键随即更新，旧组合不再触发。
2. 选择一个输入设备，重新开始录音，确认 API 使用所选设备；选择“System default”后恢复默认设备。
3. 重启桌面应用，确认两项设置仍被加载。
