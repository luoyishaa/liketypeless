# 0009. 录音状态使用独立无焦点悬浮窗

## 决策

全局快捷键录音的状态提示由 Electron 主进程创建独立的透明悬浮窗，不复用主设置窗口，也不只依赖系统通知。

悬浮窗固定在主显示器工作区右下角，具备 `alwaysOnTop`、`focusable: false`、`skipTaskbar` 和鼠标事件穿透属性。它只展示四个短暂状态：录音中、处理中、已输入、处理失败。

## 原因

用户通常在其他应用中触发快捷键，主窗口可能被隐藏。系统通知不能持续表达“正在录音”，而把状态显示在主窗口会迫使用户切换焦点，破坏恢复原输入框并粘贴的路径。

## 后果

- 首次快捷键成功启动录音后，悬浮窗持续显示；第二次快捷键后立即切换为处理中。
- 成功粘贴后 1.4 秒隐藏；失败后 4 秒隐藏，系统通知仍保留详细错误信息。
- 悬浮窗的文案只由主进程生成，不接收网页内容或用户输入，避免为该提示面引入额外 IPC 面。
- 多显示器的目标选择当前遵循主显示器；后续若增加鼠标位置或可拖拽定位，应保留不抢焦点与鼠标穿透的约束。

## 验证

1. 在记事本或浏览器输入框中按一次全局快捷键，确认右下角出现“正在录音”，且原应用仍保持焦点。
2. 再按一次，确认悬浮窗先显示“正在处理”，随后显示“已输入”并自动隐藏，文本被粘贴到原输入框。
3. 停止本地 API 后触发快捷键，确认悬浮窗显示失败状态并自动隐藏。
